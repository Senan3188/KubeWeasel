# KubeWeasel 0.3.0

## Persistent dashboard access on a private network

Install with a dashboard URL and your node's private IP:

```sh
bash install.sh install \
  --private-http http://deploy.example.internal:7878 \
  --listen-address 100.73.28.50
```

Use `upgrade` instead of `install` for an existing installation. The installer discovers the matching node, waits for readiness and prints the direct URL. No terminal, SSH tunnel or port-forward needs to stay open. `status` and `open` also show the configured URL. Subsequent upgrades retain access settings.

Configure DNS to resolve to the chosen IP and permit the selected TCP port through your private-network policy. The address must be one node's RFC1918 or NetBird/CGNAT InternalIP; wildcard/public listen addresses are rejected. The port must be free and between 1024 and 65535. The optional gateway uses host networking, which must be allowed by cluster admission policies.

Private HTTP is intended for a trusted LAN or encrypted VPN; it does not encrypt traffic itself. Internet exposure still requires HTTPS. Owner login, Host/Origin validation and CSRF checks remain enabled. HTTP uses an HttpOnly SameSite=Strict session cookie without Secure or HSTS. HTTPS origin configuration and its Secure cookies remain unchanged.

## Upgrade and storage

The gateway has no account-volume mount or Kubernetes token. Account storage stays on its existing node, including node-local storage on another worker. Existing owners and projects remain intact. Recreate updates briefly interrupt dashboard access; application workloads keep running.

Back up the account SQLite database and matching `.cluster-key` together before upgrading, alongside separate application/database backups. Uninstall retains account storage, workloads and application volumes. Reinstall with the same namespace/release and the same private-access options to resume the existing account.

Helm 3.12+ and Helm 4 are supported. Default installation without access flags retains local port-forward access. Images support Linux AMD64 and ARM64.
