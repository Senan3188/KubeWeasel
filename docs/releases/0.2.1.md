# KubeWeasel 0.2.1

Fix installation with Helm 4 while retaining Helm 3.12+ compatibility. All cluster and node-management features from v0.2.0 are included.

## Fixed

- Helm 4 no longer receives the removed `helm list --all` flag. Helm 3 still receives it, preserving detection of pending and other non-default release states.
- Listing/API errors still stop the installer before any install or upgrade, instead of being treated as an absent release.
- Added regression checks for Helm 4 fresh installation, existing-release detection, upgrade value preservation and listing failures. CI now validates real Helm 3 and Helm 4 command parsing and chart rendering.

## Install

```sh
bash install.sh install --version 0.2.1 --context YOUR_CONTEXT --namespace kubeweasel
# Existing installation:
bash install.sh upgrade --version 0.2.1 --context YOUR_CONTEXT --namespace kubeweasel
```

Download this release's installer; older copies keep their original default version and behavior. Existing installations that only encountered the `unknown flag: --all` error were not modified by that failed attempt and can rerun `install` with the corrected installer.

Linux AMD64 and ARM64 images, the chart, installer and SHA-256 checksums are published together. Account/database formats and Kubernetes permissions are unchanged from v0.2.0. Preserve your account volume and back up the SQLite database and matching cluster encryption key before upgrading; see the [v0.2.0 upgrade notes](https://github.com/Senan3188/KubeWeasel/releases/tag/v0.2.0).
